# Notebooks

This folder will contain the main notebooks for the project:

- 01_dataset_overview.ipynb
- 02_otsu_baseline.ipynb
- 03_random_forest.ipynb
- 04_cnn.ipynb
- 05_evaluation.ipynb

- train and evaluate the Random Forest
- train and evaluate the CNN
- compare all methods together in the final evaluation notebook
- The final interpretation of the project results is contained in:
  notebooks/05_evaluation_and_comparison.ipynb
